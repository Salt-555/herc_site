# Agent Guide

Static browser animation site for Gaylord's Shop. No build step, no framework, no server-side file scanning.

## Directory Structure

```text
herc_site/
  index.html                         Main page (loads all layers + manifests)
  script.js                          Idle state machine, pathways, TV + Game Cabinet playback, hotspot positioning
  styles.css                         Fullscreen layout, layer stack, clip-paths, eyelid animations
  smoke.js                           Independent canvas smoke particle effect
  Media/
    Processed_Gaylords_Shop/         Alpha-masked character WebMs (gitignored, regenerated by script)
      Idle_photo.jpg                 Static JPG fallback (copied from source)
      Idle_photo.webm                Looping idle base with alpha (generated from JPG + TVMask)
      idle_blink.webm                Idle clips (VP9 alpha)
      idle_speech1.webm
      ...
    BG_TV/                           TV background clips (committed)
      manifest.js                    window.BG_TV_CHANNELS = [...]
      notld_tv_01.webm
      ...
    Game_Cabinet/                    Game cabinet background clips (WebMs committed, MP4 sources gitignored)
      manifest.js                    window.GAME_CABINET_CHANNELS = [...]
      Bad_Bug.webm
      ...
    Videos_Gaylords_Shop/            Source MP4s + TVMask.png (gitignored, not used by site directly)
      TVMask.png                     1024x1024 alpha mask (white=opaque, transparent=TV/cabinet holes)
      idle_blink.mp4                 Source character animations (1440x1440)
      Idle_photo.jpg                 Source still frame (1024x1024)
      ...
  scripts/
    mask-gaylord-videos.sh           Two-step alpha mask pipeline: MP4 -> RGBA PNGs -> VP9 alpha WebM
    process-bg-tv.sh                 Converts source video into small keystoned TV WebM
    process-game-cabinet.sh          Converts source MP4 into small keystoned Game Cabinet WebM
```

## Layer Stack

```text
z1    tv-player              Clipped TV background video (positioned via JS, clip-path in CSS)
z1    game-cabinet-player    Clipped game cabinet background video (same z-level, separate position)
z2    idle-image             JPG fallback (1024x1024, always present for sizing)
z3    idle-base-player       Looping base WebM with alpha holes for TV + cabinet
z4    animation-player       Foreground idle/pathway clips (VP9 alpha)
z100  smoke-canvas           Smoke particle overlay
z150  hotspots               Invisible click zones
z200  back-button            Pathway-only Go Back button
z9999 eye-overlay            Opening/closing eyelids
```

TV and Game Cabinet videos sit behind the alpha-masked base/foreground WebMs. The alpha holes in the character WebMs let the background layers show through.

## Animation Model

States in `script.js`:

```text
IDLE                 Base loop playing, waiting for random idle clip timer
LOADING_IDLE_CLIP    Idle clip loading (canplay triggers playback)
PLAYING_IDLE_CLIP    Idle clip playing over base (ends -> return to IDLE)
PATHWAY              Pathway clip playing (pauses on final frame, back button visible)
```

Idle clips start/end on the same base pose. Randomly chosen every 5-15s. Pathway clips triggered by hotspot clicks; Go Back closes eyelids and reloads.

## Coordinate Systems

Two coordinate systems -- do NOT mix them.

**1024x1024 (JPG/hotspot space)** -- used for clickable hotspots and Game Cabinet screen position:

```js
// Hotspots
{ element: tvHotspot,   left: 142, top: 352, width: 173, height: 128 }
{ element: gameHotspot, left: 726, top: 410, width: 203, height: 290 }

// Game Cabinet screen corners (GAME_CABINET_SCREEN, baseWidth: 1024)
topLeft: 759,490  topRight: 881,491  bottomLeft: 764,608  bottomRight: 889,600
```

**1440x1440 (WebM/video space)** -- used for TV screen position:

```js
// TV screen corners (TV_SCREEN, baseWidth: 1440)
topLeft: 221,508  topRight: 394,518  bottomLeft: 217,660  bottomRight: 396,658
```

Both are scaled to the rendered scene via `sceneRect` from the idle-image element.

## Alpha Mask Pipeline (Two-Step)

All character WebMs are generated from source MP4s using `scripts/mask-gaylord-videos.sh`:

**Step 1** -- Extract RGBA PNG frames with mask alpha applied:
```bash
ffmpeg -y -i video.mp4 -loop 1 -t $duration -i TVMask.png \
  -filter_complex "[1:v]scale=WxH:flags=lanczos,format=rgba[mask];[0:v]format=rgba[vid];[vid][mask]blend=all_mode=and:all_opacity=1:all_expr='A*B/255',format=rgba[out]" \
  -map "[out]" -t $duration frames/frame_%05d.png
```

**Step 2** -- Encode PNGs to VP9 alpha WebM:
```bash
ffmpeg -y -framerate $fps -i frames/frame_%05d.png \
  -c:v libvpx-vp9 -pix_fmt yuva420p -auto-alt-ref 0 -crf 28 -b:v 0 -an output.webm
```

Key facts:
- Single-pass `alphamerge` does NOT work -- produces opaque pixels despite correct metadata.
- `-t "$duration"` required on both mask input and output (mask `-loop 1` creates infinite stream).
- `ffprobe` reports `pix_fmt=yuv420p` even when alpha IS present. Check `TAG:alpha_mode=1` instead.
- For still images (Idle_photo.jpg), first create an MP4 (`ffmpeg -loop 1 -framerate 24 -t 5 -i photo.jpg ...`), then run through the mask script.

Generate all processed WebMs:
```bash
scripts/mask-gaylord-videos.sh          # Skip existing
FORCE=1 scripts/mask-gaylord-videos.sh  # Rebuild all
scripts/mask-gaylord-videos.sh --dry-run
```

## Adding Background Clips

### TV (BG_TV)

Process source footage and add to manifest:

```bash
scripts/process-bg-tv.sh input.mp4 Media/BG_TV/output.webm [duration] [start-time]
```

Then add to `Media/BG_TV/manifest.js`:
```js
window.BG_TV_CHANNELS = [
    'Media/BG_TV/notld_tv_01.webm',
    'Media/BG_TV/new_clip.webm'
];
```

### Game Cabinet

Drop source MP4s into `Media/Game_Cabinet/`, then run:

```bash
scripts/process-game-cabinet.sh
```

This batch-processes all MP4s to keystoned VP9 WebMs (130x118, 12fps). Then add to `Media/Game_Cabinet/manifest.js`:
```js
window.GAME_CABINET_CHANNELS = [
    'Media/Game_Cabinet/clip_name.webm'
];
```

Both systems: single clip loops, multiple clips rotate randomly without consecutive repeats.

## Adding Idle Clips

Place source MP4 in `Media/Videos_Gaylords_Shop/`, run `scripts/mask-gaylord-videos.sh`, then add to `CONFIG.idleClips` in `script.js`:

```js
{ id: 'new-idle', src: `${MEDIA_PATH}new_idle.webm` }
```

All idle clips must be VP9 alpha WebMs so TV/cabinet layers show through.

## Adding Pathways

Add clip path under `CONFIG.pathways` in `script.js`. Add/reuse a hotspot element in `index.html`. Include it in `hideHotspots()`, `showHotspots()`, and `updateHotspotPositions()`. Trigger with:

```js
playPathwayClip(selectedClip);
```

## Alpha Verification

Check alpha metadata:
```bash
ffprobe -v error -select_streams v:0 \
  -show_entries stream_tags=alpha_mode -of default file.webm
```
Expected: `TAG:alpha_mode=1`

Decode and verify actual transparent pixels:
```bash
ffmpeg -y -c:v libvpx-vp9 -i file.webm -frames:v 1 -update 1 -pix_fmt rgba /tmp/decoded.png
magick /tmp/decoded.png -crop 1x1+300+600 txt:-
```
Transparent area should show `alpha=0`. Do NOT trust `ffprobe pix_fmt` alone.
